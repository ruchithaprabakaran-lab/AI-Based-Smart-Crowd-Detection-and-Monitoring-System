System Architecture & Project Details

Project Objective

Automate crowd monitoring and early warning estimation for high-gathering venues (political meetings, temple gatherings, festivals, cultural celebrations) to prevent overcrowding bottlenecks and stampede risks.

Four Density Classification Zones

Low Density Normal Crowd, free movement.
Medium Density Crowd Increasing, advisory caution.
High Density Attention Required, bottleneck risks.
Critical Density Immediate Attention Required, danger of crush.

Privacy & Safety By Design

Strictly detects human presence without facial recognition, identity tracing, or biometric storage. Includes an automated face/head Gaussian blur anonymizer to ensure complete GDPR/privacy compliance.

Tech Stack

  • AI Core: Ultralytics YOLOv8 (Class 0: Person) with OpenCV fallback
  • Backend: Python FastAPI + Uvicorn + SQLite DB
  • Visual Analytics: Gaussian Heatmap Accumulator & Chart.js Time-Series
  • Frontend: Modern Responsive Tailwind CSS + Web Audio API Synthesis
